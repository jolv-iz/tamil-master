# Tamil Master - Language Learning Game

A mobile-friendly Tamil language learning application with flashcards, quizzes, and games.

## Features

- 📚 **Learn Mode**: Randomized flashcards with 108 Tamil words
- 🎯 **Quiz Mode**: Multiple choice questions with score tracking
- 🔄 **Opposites Game**: Match opposite word pairs
- 📝 **Vocab List**: Complete vocabulary reference organized by category

## Categories Covered

- Time & Greetings
- Family Members
- Question Words
- Pronouns
- Directions
- Adjectives
- Personal Pronouns (Like, Want, Understand, Know, Enough)
- Taste & Location
- Common Words

## How to Use

Simply open `index.html` in any web browser. The app works completely offline once loaded!

### Add to iPhone Home Screen

1. Open the page in Safari
2. Tap the Share button
3. Select "Add to Home Screen"
4. Access like a native app!

## Score Tracking

Your quiz statistics are automatically saved to your device using localStorage:
- Total questions answered
- Accuracy percentage
- Current streak
- Total correct answers
